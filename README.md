# frame-graph

This repo is an experiment in exploring representations of identity. I trained a variational autoencoder on the CelebA dataset and then passed a live webcam feed of the viewer's face to the trained model. The result retains some semblance of identity but is heavily distorted and strangely celebri-fied. I added an interface that enables interactively tuning latents, which allows you to explore how moving in different directions in latent space morphs your identity in different ways.

For video demos of the results, see the [section in my portfolio](https://ericnlchen.com/portfolio/#pull)
